# F-009: GPU parity gates fail on backend edge and blend differences

Status: Confirmed
Priority: High
Area: GPU / Hosting
Related concerns:
Related hypotheses:
GitHub Issue:
Confidence: High

Summary:
Synthetic and Colorado 256px failures reproduce with identical recorded Skia
commands on CPU/GPU surfaces. Antialiased strokes dominate the synthetic failure;
Colorado combines landcover, road and street-label raster differences.

Conclusion:
These fixtures localize the mismatch to backend rasterization/blending. They do
not establish which backend is more accurate. Requested 4/8-sample surfaces and
filled stroke outlines do not resolve the failing complete-image gates.

Evidence:
- [Investigation, controls and validation](../Gpu-Parity-2026-09-05.md).
- [Machine-readable matrix and input hashes](../Gpu-Parity-2026-09-05-summary.json).
- 19 CPU/default-GPU picture replays exactly reproduce production outputs;
  57 GPU layer/sample replays repeat identically with checked texture readback.
- Raw Skia AA-on width-2 strokes reproduce mean error 2.34465; a translucent
  rectangle reproduces a two-level green-channel interior difference.

Impact:
Whole-image error depends on edge density/composition. Neither a relaxed mean
threshold nor exact CPU equality alone establishes correct feature rendering.
Current GPU acceptance remains blocked by the original gates.

Scope:
Windows RTX 4070 Ti OpenGL, SkiaSharp 3.119.2, two 256px fixtures. Other native
backends, drivers and devices have not been compared by this investigation.

Recommendation:
Develop independent primitive coverage checks and backend-specific references,
retaining missing-feature, displacement, alpha and readback checks. Keep CPU as
the baseline until a replacement acceptance policy is explicitly evaluated.

Suggested refactor items:
- R-001 in [Refactor Plan](../../03_Target-State/Refactor-Plan.md).

Open questions:
- Which acceptance criteria distinguish acceptable edge variation from lost or
  displaced geometry, without treating CPU pixels as an independent oracle?
- Which native Skia paths account for the measured coverage/color differences?

Notes:
2026-09-05, baseline 7bc45e1 plus local label/readback/Auto fixes. No production
rendering or tolerance changes made for this investigation. No remote issue posted.
