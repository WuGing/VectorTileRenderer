# F-007: Profiles conflate text with finish/readback and rely on caller backend hints

Status: Confirmed
Priority: Medium
Area: Rendering, GPU / Hosting
Related concerns:
Related hypotheses: H-001
GitHub Issue:
Confidence: High

Summary:
Renderer records textEnd after FinishDrawing and fills Backend from CurrentBackendHint. Mapsui resolves the hint before StartDrawing may fail GPU surface creation.

Conclusion:
DrawTextMs includes finalization/readback, and the hint can disagree with the actual surface backend.

Evidence:
- VectorTileRenderer/Renderer.cs:641-661; Mapsui.Demo.WPF/VectorMbTilesProvider.cs:180-200,277-286.

Impact:
CPU/GPU comparisons can misattribute time or count fallback tiles as GPU.

Scope:
RenderProfile consumers and performance experiments.

Recommendation:
Report actual backend after rendering and separate finish/readback, encode/write, queue and end-to-end request timings.
