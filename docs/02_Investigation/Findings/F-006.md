# F-006: Disk cache lacks eviction and source-data identity

Status: Confirmed
Priority: Medium
Area: Caching
Related concerns:
Related hypotheses: H-001
GitHub Issue:
Confidence: High

Summary:
RenderCached keys on style hash, output options and tile coordinates. It never purges files and does not include provider/source revision in the key.

Conclusion:
Shared cache directories can retain stale images when providers change under an unchanged style; storage has no built-in bound.

Evidence:
- VectorTileRenderer/Renderer.cs:69-137; README.md Known issues.

Impact:
Unbounded disk usage and potential stale imagery. Caller-level cache directory partitioning can mitigate identity collisions.

Scope:
RenderCached and demo cache directories.

Recommendation:
Specify size/age policy, versioned source identity and invalidation. Cover changed provider, corrupt cache files, and concurrent requests.
