# F-008: Canvas output remains coupled to SkiaSharp

Status: Confirmed
Priority: Medium
Area: Rendering
Related concerns:
Related hypotheses: 
GitHub Issue:
Confidence: High

Summary:
ICanvas.FinishDrawing and Renderer.Render return SKBitmap.

Conclusion:
Alternative drawing engines need a bitmap adapter or an output-contract migration; the abstraction is not engine-neutral.

Evidence:
- VectorTileRenderer/ICanvas.cs:27; VectorTileRenderer/Renderer.cs:142; VectorTileRenderer/VectorTileRenderer.csproj.

Impact:
Replacement cost includes API compatibility, memory transfer and desktop presentation, not only translating draw calls.

Scope:
Public library API and all demos.

Recommendation:
Keep current API while measuring a bounded alternative spike; propose and define any new output API before implementation.
